## Question: "yesterday" — `Mijal` vs `Mejal`/`me·ja·o`

We already have full confirmation for "yesterday" = `Mejal` (also
written `me·ja·o`), both VERIFIED/HIGH.

This is **not** what we're asking about — that word is settled.

Two existing sentences in our data use a different spelling, `Mijal`,
for the same word "yesterday":
- "he came by bus yesterday" = *Bia bus o raba·a mijalo*
- "how was the journey yesterday?" = *Mijal songre·ara namama?*

Neither of these sentences has ever been directly confirmed by you —
they're unverified. We don't know if `Mijal` is:
(a) the same word as `Mejal`, just written differently (e.g. a raka
    placement or vowel-spelling difference), or
(b) a mistake — someone misheard or mistyped `Mejal` as `Mijal`, or
(c) an actually different word (unlikely given the shared meaning,
    but we don't want to assume).

**Question for Thangseng:**

> Is "Mijal" the same word as "Mejal" (yesterday), just spelled
> differently — or is it a mistake, or a different word? If it's the
> same word, which spelling is more correct: Mejal, Mijal, or
> me·ja·o?

**Why we're asking:** so we can correctly reconcile these two
sentences (either fix their spelling to match the confirmed `Mejal`,
or, if `Mijal` turns out to be a genuinely valid alternate, confirm it
as a variant) without guessing.

**Does not block other work:** nothing else depends on this — the two
affected sentences are already flagged unverified and aren't shipping
as confirmed data.
