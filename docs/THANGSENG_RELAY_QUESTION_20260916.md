**Part 1 — same verb, every question word.**
Using the verb "eat," please give the natural Garo sentence for each
of these. The goal is to see whether the ending of the verb changes
depending on the question word, so please answer in the same style
each time rather than paraphrasing:

1. Who ate?
2. What did you eat?
3. Where did you eat?
4. Why did you eat?
5. How did you eat?
6. Which food did you eat?

(We already have "When did you eat?" = *Na·a basako cha·aha?* on

for comparison.)

**Part 2 — "who called?".**
We have two forms on file for this: *Sawa ka·ata?* (calling on the
phone) and *Sawa okamata?* (calling/summoning someone to come to a
place). Two questions:
- Is *-ata* attached directly to the verb (no gap) the right way to
  ask this, or would *Sawa ka·a na·ara?* / *Sawa okama na·ara?* (verb,
  then a separate word *na·ara*) also work, or work better?
- If both are acceptable, is there any difference between them (e.g.
  more formal/casual, or a difference in when the calling happened)?
