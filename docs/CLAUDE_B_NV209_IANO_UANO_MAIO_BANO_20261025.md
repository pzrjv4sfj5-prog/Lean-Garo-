# NV-209: iano / uano bare, maio vs bano, past-intent questions (Claude B, 2026-10-25)
Source: Thangseng answers relayed by the PO 2026-10-25.

1. **"Iano and uano are correct."** Applied as: both locatives are written bare (no -ko) for every non-directional verb and for negative motion. `I sit here` = Anga iano asonga; `I did not go there` = Anga uano re·angja; `I will not go there` = Anga uano re·jawa. Directional go/come in non-negative clauses stays Uchi / Iachi (NV-200, directly attested). Supersedes the NV-195 "iano only with donga" scope and the old `ianoko` / `uanoko` defaults (4 older assertions updated).
   *Reading note:* the message gives no sentence, so I read it as answering the open `-ko` on locatives and `uana` vs `uano` questions. If it meant only the bare forms exist and -ko is still allowed somewhere, tell me.
2. **Past questions:** a simple "past" question is present in form and past in intention; context carries the tense (general conversation). So `Na·a bano re·anga?` is normal for "where / which did you go".
3. **maio vs bano:** mode of transport -> `Na·a maio re·anga?` (how did you go / what did you go by). When choosing among several vehicles and asking which one was taken -> `bano` (`Na·a bano re·anga?`). Added rows: how did you go / by what did you go / what did you go by = maio; which vehicle did you take / go by = bano.

Open: `how did you come` / `how will you go` (maio with re·baa / future) are unattested; the engine still gives the old `Maidake ...` shape for them. `bano` stays "where" in `Na·a bano tanga?` (where do you live).
