# NV-224 (A), 2026-10-28: sia / sina (Project Owner statement)

- `sia` = die (verb root, no raka). `sina` = sia + infinitive `-na` = "to die", the same `-na` seen in `cha·na`, `re·angna`, `tusina`.
- Example: `Sina skengama?` = "Do you want to die?" (infinitive + `skenga` + question `-ma`).
- Stored: `die` = sia, `to die` = sina, `do you want to die?` = Sina skengama? (verified_high, provenance: Project Owner statement). Old unverified `die` = `si·a` is a raka typo and is superseded; other `si·a` headwords are different senses and untouched.
