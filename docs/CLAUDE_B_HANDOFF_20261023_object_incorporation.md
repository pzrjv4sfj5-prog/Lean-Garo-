# Claude B handoff: object incorporation (bare-noun object, no `-ko`), 2026-10-23

Source: Project Owner directive NV-192 (relayed as native-verified; not a native quote).

**Rule (conversational):** a tightly bound, habitual object + verb pair may take the bare noun without the accusative `-ko`.

**Evidence so far (only this):** `I ate rice` = `Anga mi cha·aha` (NV-089, verified). Related, already live: common-noun object drops `-ko` before `ska` / `skenga` (NV-153, `Anga momo cha·na ska`) and in purpose clauses (RULE for `grammar.purposeAction`).

**Current engine:** only the `mi` + `cha·` pin is bare. `I eat rice` -> `Anga miko Cha·a` and `I ate fish` -> `Anga na·tokko Cha·aha` (grammar-assembly, `-ko` kept). Not changed, because no native evidence covers other pairs or tenses.

**For Claude B:** if generalizing, scope it to a verified list of bound pairs (start with `mi` + `cha·`, all tenses) and get a native / PO ruling per additional pair. Do not drop `-ko` for all nouns. Keep `-ko` licensed where other rules require it (RULE-052 adverb case, NV-153 exceptions). Tests first; run the full gate.
