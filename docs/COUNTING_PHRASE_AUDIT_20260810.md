## Why this exists

Per `docs/CLAUDE_B_MIGRATION_20260809.md` §3.E: a prior session found 413
`"<number> <noun>"` entries disagreeing with `garo_classifier.js`'s already-
confirmed classifier-composition system, initially auto-corrected all of them,
then reverted after finding Claude A/Thangseng had deliberately confirmed only
the 3 dog-count keys and left the rest — including the structurally-identical
`"three cat"` — untouched pending individual native confirmation. This report
re-runs that same audit as a read-only tool, so the remaining candidates are a
concrete, reviewable list rather than a one-time finding that could go stale.

**Every value below is a mechanically-derived candidate, not a confirmed
correction.** Some may be genuinely wrong (transcription/OCR errors, the same
shape as the dog case); others may be legitimate exceptions where this noun
genuinely doesn't follow the regular count-word pattern (irregular counting,
idiom, dialect) — that distinction is exactly what needs native review, and is
why this stays a report, not a script that writes to the dictionaries.
